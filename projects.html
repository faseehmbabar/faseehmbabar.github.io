Author Website

After publishing "The Huntsman", I wanted to create a place where readers could learn more about the book, find my work, and follow my journey as a writer. So I decided to build the website myself. I designed and developed my personal author portfolio using HTML, CSS, and JavaScript, customized the entire site to fit my identity as an author and a CS enthusiast, and set it up with GitHub Pages domain and GitHub repository. It also gave me a chance to learn more about things beyond just writing code, from responsive design and SEO to deployment and maintaining a real website.

Private Search Engine

I set up a self-hosted search environment using SearXNG and Docker Desktop, giving me a private and customizable alternative to traditional search platforms. The project involved configuring the SearXNG container environment, generating a secure instance secret, managing environment variables, and deploying the service through Docker Compose. I also documented the entire setup process in my GitHub repository, including the configuration and commands required to reproduce the environment from scratch.
